# Retail Sales Performance Interactive Dashboard (2025)

An end-to-end business intelligence dashboard built in Microsoft Excel to monitor, filter, and analyze multi-regional retail transaction performance across 2025.

---

## 📊 Dashboard Preview

![Sales Dashboard Preview](dashboard_preview.png)

---

## 🚀 Key Features

* **Dynamic Multi-Dimensional Filtering:** Fully synchronized slicers allowing instant filtering by month, product category, and geography across all visualizations.
* **Core Business Visualizations:**
  * **Sales by Category:** Donut/Pie chart highlighting product mix contribution.
  * **Sales by City:** Trendline monitoring geographic sales distribution across key metros.
  * **Product Volume Breakdown:** Clustered bar charts tracking high-margin hardware (laptops, smartphones) vs. volume drivers (audio accessories).
  * **Sales Representative Benchmarks:** Horizontal ranking tracking individual sales targets and performance.
* **Automated Data Architecture:** Multi-tab layout separating raw data entry (`Sales_Data_2025`), aggregated data modeling (`PivotTables`), and presentation interface (`Dashboards`).

---

## 🛠️ Tools & Techniques Used

* **Microsoft Excel:** Pivot Tables, Pivot Charts, Slicers & Report Connections, Data Modeling, Number & Currency Formatting.
* **Data Fields Tracked:** Date, Product, Category, Sales Rep, City, Units Sold, Unit Price, Total Revenue.
